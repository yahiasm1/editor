# The engine

`engine/full-visual/`. Every command below runs from there. Python runs through the folder's runner, so no
`python3` on the PATH is needed.

```bash
node ../../scripts/py.mjs scripts/voice.py <slug>          # script.v3.txt -> voice.mp3 + voice.alignment.json, one whole take
node ../../scripts/py.mjs scripts/tighten.py <slug> --cap 0.2 --keep "<paragraph starts>:0.30,..."
node ../../scripts/py.mjs scripts/align.py <slug>          # caption.txt + voice -> words.json
node ../../scripts/py.mjs scripts/check.py plan <slug>     # before any pixel: caption, key words, pace, handovers in silence
node render.mjs <slug> --stills 1.2,3.45,9                 # reels/<slug>/stills/, seconds; all the stills you need in one call
node render.mjs <slug> --guides --stills 9                 # the bands and Instagram's zones drawn on
node render.mjs <slug> [--from s --to s] [--out path]      # output/YYYY-MM-DD/NN-<slug>.mp4
node render.mjs <slug> --gl angle ...                      # a scene that uses WebGL (three.js)
node render.mjs <slug> --full-public ...                   # a reel whose scenes load another reel's public/ folder
node ../../scripts/py.mjs scripts/check.py render <slug> <mp4>   # dead holds, bare ground in a handover
node ../../node_modules/typescript/bin/tsc --noEmit -p .   # types, before any render
```

## A reel

```
reels/<slug>/
  script.txt          the spoken words, plain
  script.v3.txt       the same words with voice tags, numbers spelled out (voice.md)
  voice.mp3 + voice.alignment.json
  caption.txt         the script as caption blocks and scenes (below)
  words.json          generated by align.py
  reel.json           the voice, theme overrides, pinned chrome
  facts.md            every claim: claim | evidence | URL, checked the day it was written
  plan.md             the visual plan
  assets/refs/        the real photos, screens and footage the scenes are drawn from
  notes/              each builder's looking and thinking (builder.md)
  scenes/index.tsx    scene id -> component; scenes/*.tsx one file per scene, helpers prefixed by its name
public/<slug>/        what scenes load with staticFile("<slug>/<file>")
```

A reel registers itself: `reels/index.ts` finds every `reels/<slug>/scenes/index.tsx`. A hook variant `reels/<slug>-hN`
holds the same `caption.txt`, `words.json`, `reel.json` and voice, and a `scenes/index.tsx` that spreads the base map
and swaps the hook:

```tsx
import type { SceneMap } from "../../../src/engine/Stage";
import { scenes as base } from "../../<slug>/scenes";
import { HookX2 } from "../../<slug>/scenes/HookX2";

export const scenes: SceneMap = { ...base, hook: HookX2 };
```

## caption.txt

```
== hook | ground: dark             a scene: its id (the key in scenes/index.tsx) and its ground, dark or light
Your phone screen / reacts to the  one line = one caption block, " / " breaks the rendered line
lightest *brush* of your finger    *word* = the key word, boxed
== answer | ground: dark
💬 So what is it actually *feeling?*   an emoji right before a word sits inline before it
@bottom                            the caption moves under the stage from the next block on (@top to come back)
```

- A block is one breath of 2 to 7 words, never more than two lines. It ends at a clause end, or right before the
  word the picture is about to show, so that word opens a fresh line.
- One key word per block at most: numbers, names, the verb that carries the idea. Read alone, top to bottom, the key
  words are the argument.
- A scene starts where a sentence starts. `check.py plan` refuses a boundary with less than 0.15 s of silence.
- Read every "!" line `align.py` prints: each is a place where the viewer would read one thing and hear another.

## A scene

A React component that reads `useScene()`: `f` (the frame), `cue("word")` (the frame that word starts, inside this
scene; `"it#2"` for the second one; it throws when the word is not in the caption), `cueEnd`, `endsOn("word", dur)`
(where a build of `dur` frames must start to finish on the word), `scene.from`, the ground and the theme. It draws
inside `<Column>`. The next scene is mounted 6 frames early (`LEAD`): start its first entrance at
`scene.from - LEAD`. A scene with `MyScene.keep = true` hands over in place, the next one starting on the same picture
(the PewDiePie map does this).

The kit (`src/engine/moves.ts`, `Motion.tsx`), durations in frames at 60 fps: `blurIn` (7 f, the default arrival),
`pop` (8 f, small overshoot), `<Travel>` (in 12 f over 260 px, blur along the travel), `blurOut`, `typeOn` (36 ms a
character), `countTo` with `jitter` (every number), `stagger` (4, 6, 8 or 12 f between siblings), `mix` (recolour in
place), `draw` (along a path), `<Cursor>` (eased arcs, rests before a click). The kit is verbs: what a reel draws is
written for that reel.

## Sync

- An event lands on its word, within a frame or two: `at={cue("touch")}`.
- A build ends on its word: `at={endsOn("300", 17)}` starts a 17-frame build so it lands as "300" is said.
- A counter finishes before its sentence does. A colour flips on the frame the data crosses, not on a word.
- The key-word box follows its word by about 5 frames. The engine leads the caption word a little, so it is sharp
  on the syllable.
- `check.py render` fails a still stretch over 1.2 s and any frame of bare ground in a handover.

## Real material

- Fetch real logos bare (no tile, no white circle). Redraw interfaces at their real geometry, type and copy.
- Footage: H.264, `-c:v libx264 -g 1 -crf 18 -preset slow -pix_fmt yuv420p`, muted, into `public/<slug>/`.
- People are real portraits or realistic synthetic faces with a name, consistent across scenes. Never initials.
- Type below 32 px is texture, not evidence. Fewer rows, bigger.

## Depth and 3D

Canvas 2D carries most worlds: one camera in real units, a projection, a light, drawn every frame
(`examples/pewdiepie-abliteration/code/map.ts`, `MapSpace.tsx`, `HookX2World.ts`). three.js is installed
(`@remotion/three`, `three`, `@react-three/fiber`) for a real object turned in light; render those with `--gl angle`.

## Many builders at once

The machine is shared by every builder of the reel. Renders queue themselves in `render.mjs`; every render call
bundles the project, so ask for all your stills in one call. Never run a render or the type check in the background.
Take turns on the type check:

```bash
until mkdir .tsc.lock 2>/dev/null; do sleep 4; done; node ../../node_modules/typescript/bin/tsc --noEmit -p .; rmdir .tsc.lock
```

A `.tsc.lock` older than ten minutes belongs to an agent that died: remove it. Disk: renders and stills are big;
delete your old stills, and stop and say so when the disk has under 2 GB free.
